pycoop.viz

Visualization: graph snapshots, trajectory traces, animation, scrubbing.

Actions color the nodes (diverging colormap over [-1, 1]); opinions set the node border (dark = +1, light = -1). Change-of-heart bands [l, u] and [-u, -l] are shaded in trace plots.

pycoop.viz.snapshot(G, sigma, q=None, ax=None, pos=None, cmap='coolwarm', node_size=300, colorbar=False)[source]

Draw the graph with nodes colored by action and, if given, bordered by opinion. Returns (ax, pos).

pycoop.viz.traces(traj, players=None, ax=None, bands=True, flips=True, cmap='tab10', lw=1.2)[source]

Action time series sigma_i(t) with change-of-heart bands and flip markers. Positions are exact at event times; segments between are drawn straight (exact up to wall clipping within an interval).

pycoop.viz.animate(traj, G=None, pos=None, stride=1, interval=50, cmap='coolwarm', node_size=300)[source]

FuncAnimation over trajectory frames (every stride events).

Returns the animation; save with anim.save("run.mp4") (needs ffmpeg) or anim.save("run.gif", writer="pillow"). Keep a reference alive until saved/shown.

pycoop.viz.scrub(traj, G=None, pos=None, cmap='coolwarm', node_size=300)[source]

Interactive in-notebook frame scrubber (requires ipywidgets).
