pycoop.observables

Observables on states and trajectories.

State functions take (A, sigma) with A a zero-diagonal symmetric adjacency; the self-weighting enters through 1/(d_i + 1). Definitions follow the main text of Conrad & Tabor (2024): friends/enemies are statements about ACTIONS (sign of sigma_j), not opinions, and fraughtness is the non-Pareto-optimal Nash condition (crowd split, no single player can improve their own agreement by switching sides).

pycoop.observables.local_mean(A, sigma)[source]

sigma_bar_i = (sigma_i + sum_j A_ij sigma_j) / (d_i + 1).

pycoop.observables.agreement(A, sigma)[source]

a_i = abs(sigma_bar_i) in [0, 1].

pycoop.observables.friend_enemy_weights(A, sigma)[source]

(F, E): summed abs(sigma_j) over neighbors sharing / opposing player i’s action sign. Assumes sigma_i != 0 for all i.

pycoop.observables.alignment_asymmetry(A, sigma)[source]

y_i = F_i - E_i; y_i >= 0 means no local incentive to defect.

pycoop.observables.is_consensus(sigma)[source]

In a consensus orthant: all actions share one sign, none zero.

pycoop.observables.is_fraught(A, sigma)[source]

No zeros, non-consensus, and every y_i >= 0: split but locally content – a non-Pareto-optimal Nash equilibrium.

pycoop.observables.is_obdurate(A, sigma)[source]

No zeros, non-consensus, not fraught: some player could improve their agreement by switching sides (some y_i < 0) but is unwilling.

pycoop.observables.classify(A, sigma)[source]

One of ‘consensus’ | ‘fraught’ | ‘obdurate’ | ‘indeterminate’ (the last only when some sigma_i == 0 off consensus).

pycoop.observables.state_fractions(traj)[source]

Time-weighted fraction of the run spent in each class, evaluated at event states and weighted by the following interval (the state can change class mid-interval only by an action crossing 0 or a wall, so this is exact up to those crossings). Returns a dict.

pycoop.observables.alpha_estimate(traj, l=None, u=None)[source]

Time-weighted fraction of players past the position threshold, abs(sigma_i) > l, restricted to intervals where the global window is open, abs(mean(sigma)) < u. On K_N this estimates the active-window slope alpha = 1 - 2l/(T+2); on other graphs it is a heuristic global proxy.
